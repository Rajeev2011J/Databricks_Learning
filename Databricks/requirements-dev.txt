#  - pyspark version must match the Spark version on your clusters.

#  - delta-spark version must be compatible with pyspark (see compatibility matrix:
#    https://docs.delta.io/latest/releases.html)
#  - databricks-sdk is needed so that `from databricks.sdk.runtime import ...`
#    resolves at import time (we stub it, but the package must be present).
