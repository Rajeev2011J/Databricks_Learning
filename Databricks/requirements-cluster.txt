# =============================================================================
# requirements-cluster.txt
# Packages to %pip install inside a Databricks cluster notebook BEFORE
# running the test suite.
#
# WHAT IS EXCLUDED AND WHY
# -------------------------
# pyspark      — provided by the cluster runtime; re-installing conflicts
# delta-spark  — provided by the cluster runtime; re-installing conflicts
# pyyaml       — pre-installed on Databricks LTS runtimes (6.x)
#
# HOW THIS FILE IS USED
# ----------------------
# The test runner notebook (run_tests_notebook.py) runs:
#
#     %pip install -r /path/to/requirements-cluster.txt -q
#
# before invoking pytest. This installs only the packages that are
# genuinely missing from the cluster environment.
#
# NEXUS REGISTRY
# ---------------
# If the cluster is configured with the Nexus PyPI index (set via cluster
# env vars or Databricks secrets), pip will resolve packages from there
# automatically. No special flags are needed inside the notebook.
# =============================================================================
